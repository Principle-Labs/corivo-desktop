Corivo · Step 2A · Design System v0

把语言变成乐高。

v0.1 把"想要的质感"摊出来了;这一份把它拆成 token、组件、Light/Dark 双主题,后面所有界面都是这套乐高拼出来的——任何一个色值、间距、阴影,都能追溯到这里。

v0.1 → 2A · 这次加了四件事
  • Dark Mode · 完整的暗色主题 token,跟随系统或手动切换 — 用右上角切换可以实时看效果
  • Semantic Tokens · 引入语义层(--fg / --bg / --accent ...),组件从此不再直接引用色阶 — 这是双主题的根
  • 组件库雏形 · 把产品需要的所有基础积木都列了出来 — Button / Input / Toggle / Slider / Tabs / List / Tag / Card / Empty / Skeleton / Kbd / Toast / Dialog / Drawer
  • Brand Assets · 双 register · logo 与 mascot 作为独立资产纳入,新增 --brand-coral;Focus Mark 仍是日常系统印记,小人只在角色出场的时刻露脸
01 · Theme · Light + Dark

白天的纸,深夜的木。

Light 是纸感的暖白(被太阳晒过的纸)。Dark 不是 OLED 的死黑,是深夜书房里被台灯照过的深木桌面 —— 同样温暖,只是把光关了。两套都用同一组 amber 印记保持品牌一致。
