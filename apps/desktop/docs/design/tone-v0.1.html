Corivo · Tone Reference v0.1

工作时,
安静地在场。

v0.1 把 v0 太像 Claude 的部分退掉了——退掉 Serif、退掉 Italic、把暖白拉到纸感、把 amber 沉到印染感,加一个属于 Corivo 的取景标记。

v0 → v0.1 · 改了四件事
  • 退掉 Serif Display + Italic · 改用 SF Pro Display + 字距控制,从"杂志/书"切到"软件/工程"
  • 暖白从米色退到纸感 · #FBF8F2 → #F8F7F3,少一分"煮过",多一分自然
  • Amber 从光沉到印染 · #C8842B → #A86B22,且不再用作主操作色,只在小尺度出现
  • 加入 Focus Mark · 一个 4 角取景框 + 中心点的小图记,作为 Corivo 的视觉签名
01 · Surface & Color

纸感的暖,与一束印染的琥珀。

底色不再像"煮过的米浆",更接近真正的纸——暖,但中性。Amber 从"光感"沉到"印染感",平时退后,只在最该被看到的瞬间出现。

02 · Typography

系统字 + 字距,不再有 Serif。

全部走 SF Pro / 苹方,显著的负字距让大字"压实",eyebrow / mono 用正字距让小字"开"。气质从"杂志 / 书"切到"软件 / 工程",同时保持中文的呼吸。

Display · 48工作时,安静地在场。
H1 · 32在合适的时候,说一句合适的话
H2 · 24写作时它陪你查资料,不打断思路
H3 · 18把刚才看的页面整理成几条要点
Body L · 17这一段比正文略大,用在 lede 或对话里需要被注意到的句子。
Body · 15默认正文。中英文混排时不再追求"字距开",而是按 macOS 原生字的默认节奏走——既不挤,也不松。
Small · 13次要文字、说明、辅助标签。视觉上要"退后一步",但仍能读清楚。
Caption · 12最小可读字号,用于元数据、时间戳、技术性标签。

"刚才那个 PR 里 reviewer 提到的 race condition,具体在哪一段?" —— Corivo 在你打字时,已经从你过去 15 分钟看过的 GitHub diff 里把上下文翻了出来。它不抢答,等你说完。

这段话里中文和 English、半角与全角、code 标识与人话混在一起。useChatStream() 这样的 mono 在正文里出现时,要恰好跟正文对齐,不能凸出来一截。

03 · Surface · Borders & Shadows

0.5px 描边,双层叠影。

Retina 上 0.5px 才是真正的"线"。阴影从来不是单层——近距离的锐影定形状,远距离的弥散给重量。这一节没改,因为它本来就不是 Claude 的语言。

05 · Focus Mark · Corivo Signature

四个角,加一个心。

这是 Corivo 的视觉签名——四角 L 形 + 中心一点,像相机的 AF 取景。它说"我在看这一块,但很轻"。它会出现在 Quick Ask 的 context tag、屏幕捕捉指示器、品牌徽标位、空状态等所有"产品本质相关"的地方。

Focus Mark
Corivo · Visual Signature

结构

  • 4 个 90° 角的 L 形,留 6px 内边距,暗示"框住一块画面"
  • 中心 1.25 半径实心圆,表示"焦点在这里"
  • Stroke 1.25(24×24 viewBox),线端 round,角点 sharp
  • 颜色随上下文走:常态 ink-700;捕捉中 amber-600;深色面 ink-100

06 · A glimpse of Corivo

主窗口是纸,浮层是光。

Quick Ask 保留毛玻璃——它是浮在所有应用之上的临时存在,毛玻璃是它的语言。主窗口里的空状态走纸感。两种姿态有对比、但 Focus Mark 让它们一眼属于同一个 Corivo。

07 · Is / Isn't

用两列把判据钉死。

这八对是后面所有设计决策的快速 review 表。任何一张稿子做完,左右两列对一遍——偏向右列,就回去改。

是纸感的暖白,中性一点
不是米色"煮过"的暖,或死白工业灰
是琥珀沉到印染感,极少出现
不是琥珀像光,大面积出现
是系统字 + 字距,直接说
不是Serif + Italic 的书卷气
是主操作走深墨色
不是主操作走 amber
是0.5px 描边,双层阴影
不是1px 笔画感,单层硬阴影
是主窗口纸,浮层光
不是主浮层都用一种材质
是Focus Mark 做签名
不是通用 AI 闪光 / 流光边框
是空状态像同事说话
不是"暂无数据"
